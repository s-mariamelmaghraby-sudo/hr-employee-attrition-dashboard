# HR Employee Attrition & Workforce Analytics Dashboard 

##  Project Overview

This project is an interactive **Power BI HR Analytics Dashboard** designed to analyze employee demographics, workforce characteristics, job satisfaction, and employee attrition.

The dashboard transforms HR data into interactive visualizations and KPIs that help identify patterns related to employee turnover and workplace satisfaction.

This project was created as a learning and portfolio project while developing skills in **Data Analysis and Business Intelligence**.

---

##  Project Objectives

The main objectives of this dashboard are to:

* Analyze overall workforce size and employee characteristics.
* Monitor employee attrition and attrition rate.
* Understand employee demographics such as age, gender, education, and experience.
* Analyze employee distribution across departments and job roles.
* Explore factors related to employee satisfaction and work-life balance.
* Identify patterns between employee characteristics and attrition.
* Practice building interactive and business-focused dashboards using Power BI.

---

##  Dashboard KPIs

The dashboard provides key metrics including:

* **Total Employees**
* **Average Age**
* **Average Experience**
* **Average Salary**
* **Total Attrition**
* **Attrition Rate**

##  How to Use

1. Download the `HR Employee Attrition & Workforce Analytics Dashboard.pbix` file.
2. Open it using **Microsoft Power BI Desktop**.
3. Use the available slicers to filter the analysis by:

   * Department
   * Job Role
   * Education Field
4. Interact with the charts to explore workforce and attrition patterns.
